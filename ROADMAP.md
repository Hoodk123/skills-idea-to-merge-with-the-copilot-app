# Mona's Bookmark Manager Roadmap

A focused plan for making bookmarks easier to find, manage, and protect.

| Area | Item | Type | Priority |
| --- | --- | --- | --- |
| Discovery | Search and filter bookmarks | 🚀 | P1 |
| Editing | Edit a saved bookmark | 🚀 | P1 |
| Organization | Organize bookmarks with tags | 🚀 | P2 |
| Portability | Import and export bookmarks | 🚀 | P2 |
| Data integrity | Prevent duplicate slugs | 🐞 | P1 |
| Validation | Reject empty bookmark URLs | 🐞 | P1 |
| Persistence | Protect bookmarks from localStorage loss | 🐞 | P2 |

## 🚀 Planned features

- 🔎 Search and filter bookmarks — `#discovery`
- ✏️ Edit a saved bookmark — `#editing`
- 🏷️ Organize bookmarks with tags — `#organization`
- 📦 Import and export bookmarks — `#portability`

## 🐞 Known bugs & risks

- 🧩 Prevent duplicate slugs from colliding — `#data-integrity`
- 🔗 Reject empty URLs when saving bookmarks — `#validation`
- 💾 Warn that clearing localStorage can erase bookmarks — `#data-loss`
